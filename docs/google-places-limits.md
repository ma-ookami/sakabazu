# Google の店検索(Places API)の利用上限と予算アラート(酒場図)

作成: 2026-10-18 / 対象: Google Cloud プロジェクト `sakabazu`

---

## 1. なぜ必要か

- 酒場図の「Google で探す」は、Cloudflare Worker(`worker/hotpepper-proxy.js`)が Google の Places API を呼ぶ仕組み。
- Places API は**使った回数だけ料金がかかる**(毎月の無料枠を超えた分)。
- Worker は「酒場図のページからの呼び出しか」を、ブラウザが送る情報(Origin)で判断している。ブラウザ以外のプログラムならこの情報を偽れるので、悪意のある人に大量に呼ばれると請求が発生しうる。
- 次の2つを設定して、**使いすぎを止める仕組み(上限)**と**気づく仕組み(アラート)**を用意する。

| 設定 | 役割 |
|---|---|
| 利用上限(割り当て) | 1日に呼べる回数の上限。超えると検索が止まり、料金も増えない(**止める**) |
| 予算アラート | 月の料金が決めた額に近づいたらメールで知らせる。課金は止まらない(**気づく**) |

---

## 2. 料金の目安

- 酒場図は、営業時間・評価・口コミ数・価格帯を表示するため、Places API(New)の Text Search の上位の区分(Enterprise)を使う。
- 毎月の無料枠はおよそ 1,000 回で、超えると 1,000 回あたり数千円かかる。
  - これは 2025 年時点の情報。最新は Google Maps Platform の料金ページで確認する。
- Worker は同じ検索結果を10分間覚えて(キャッシュして)、同じ検索で何度も呼ばないようにしている。
- 個人や数人で使うなら、1日 30〜50 回あれば足りる見込み。

---

## 3. 手順

### A. API キーを Places API 専用にする(キーの制限)
1. https://console.cloud.google.com/apis/credentials (プロジェクト: sakabazu)
2. Worker に登録した API キーを開く
3. 「API の制限」→「キーを制限」→ **Places API (New)** だけにチェック → 保存

**何のためか**:キーが漏れても、ほかの有料 API には使えないようにする。

- 「アプリケーションの制限」は「なし」のままにする。Worker は Cloudflare のサーバーから呼ぶので、IP アドレスでは絞れない。

### B. 1日の利用上限を決める(割り当て)
1. https://console.cloud.google.com/apis/api/places.googleapis.com/quotas
2. 一覧から **「Text Search」の 1日あたりのリクエスト数**(SearchTextRequest per day など)を探す
3. 右の鉛筆(編集)→ 上限を **50** などにして保存
   - 1分あたりの上限があれば **10** 程度にしておくと、短時間の連打も防げる

**何のためか**:どれだけ呼ばれても、1日の料金に上限ができる。超えた日は「Google で探す」が使えなくなるだけで、ホットペッパーの検索はそのまま使える。

### C. 予算アラートを作る
1. https://console.cloud.google.com/billing → 「予算とアラート」→「予算を作成」
2. 対象プロジェクト:**sakabazu**、サービス:すべて(または Places API)
3. 金額:**月 1,000 円**など
4. アラートのしきい値:**50% / 90% / 100%** → 通知先のメールを確認して保存

**何のためか**:想定外の料金が出始めたら、すぐ気づけるようにする。予算アラートは**通知だけで、課金は止まらない**。止めるのは B の上限の役目。

### D. Worker にキーを入れる(Google 検索を有効にするとき)
- Cloudflare → Workers → `sakabazu-hp` → 設定 → 変数とシークレット → `GOOGLE_PLACES_KEY` に API キーを登録する
- `worker/hotpepper-proxy.js` の最新版(VERSION 4)を貼り付けてデプロイする

---

## 4. 運用メモ

- **料金の確認**:Google Cloud → お支払い →「レポート」で、Places API の金額を見る。
- **上限に達した日**:「Google で探す」が失敗する。普段から足りないようなら、B の上限を少し上げる。
- **アラートが来たら**:まず B の上限を下げるか、Worker の `GOOGLE_PLACES_KEY` を消して Google 検索を止める。そのあと原因を調べる。
- **さらに守りたいとき**:Cloudflare の「レート制限ルール」で、同じ相手から Worker への呼び出し回数を絞れる(無料プランは1ルールまで)。
